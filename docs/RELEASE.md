# macOS release runbook (v0.1.0)

Linux / CI cannot archive, Developer-ID-sign, or notarize this Mac app. **Jim runs this on his Mac** with Xcode + Apple Developer ID.

**Tip base for 0.1.0:** Soft OPEN UI @ `8854bc1` + Slice A docs @ `f2a785f` + this B-prep tip (pull latest `main`).

## Prerequisites

1. **Xcode 15+** (full app, not just CLT) logged into your Apple ID.
2. **Developer ID Application** certificate in Keychain (Apple Developer → Certificates).
3. **Notary credentials** — App Store Connect API key or Apple ID app-specific password stored as a `notarytool` profile:

```bash
# One-time: create a keychain profile (pick ONE method)
# A) App Store Connect API key
xcrun notarytool store-credentials "lpc-notary" \
  --key ~/Downloads/AuthKey_XXXXXX.p8 \
  --key-id KEY_ID \
  --issuer ISSUER_UUID

# B) Apple ID + app-specific password
xcrun notarytool store-credentials "lpc-notary" \
  --apple-id "you@example.com" \
  --team-id TEAM_ID \
  --password "app-specific-password"
```

4. `gh` CLI authenticated as `jim-ku` (`gh auth status`).
5. Env (or pass flags to the script):

| Var | Example | Required |
|-----|---------|----------|
| `TEAM_ID` | `AB12CD34EF` | yes |
| `SIGNING_IDENTITY` | `Developer ID Application: Jim Ku (AB12CD34EF)` | yes |
| `NOTARY_PROFILE` | `lpc-notary` | yes |
| `VERSION` | `0.1.0` | default |

Find identity:

```bash
security find-identity -v -p codesigning | grep "Developer ID Application"
```

## Exact command block (B final on Jim Mac)

```bash
cd ~/src/live-photo-converter   # or your clone path
git fetch origin && git checkout main && git pull --ff-only
git rev-parse HEAD              # confirm tip SHA

export TEAM_ID="YOUR_TEAM_ID"
export SIGNING_IDENTITY="Developer ID Application: Jim Ku (${TEAM_ID})"
export NOTARY_PROFILE="lpc-notary"
export VERSION="0.1.0"

# Archive → export Developer ID → notarize → staple → DMG
./scripts/macos-release.sh

# Smoke the DMG before publishing
open "dist/LivePhotoConverter-${VERSION}.dmg"
# Mount, drag app to /Applications (or run from DMG), follow docs/SMOKE.md
# Record tip SHA + PASS/FAIL

# Only after notarized DMG smokes green:
gh release create "v${VERSION}" \
  "dist/LivePhotoConverter-${VERSION}.dmg" \
  --title "v${VERSION}" \
  --notes-file docs/release-notes-0.1.0.md
```

Do **not** create the tag/Release until the DMG is notarized and stapled. Empty Releases are out of scope for B-prep.

## What the scripts do

| Script | Role |
|--------|------|
| `scripts/macos-release.sh` | `xcodebuild` archive + `exportOptions` Developer ID + `notarytool submit --wait` + `stapler staple` + calls `make-dmg.sh` |
| `scripts/make-dmg.sh` | Builds `dist/LivePhotoConverter-$VERSION.dmg` from a signed `.app` |

Both **exit non-zero on Linux** or when identity / notary profile is missing — they do not invent signing.

## Manual fallback (same steps as the script)

```bash
VERSION=0.1.0
SCHEME=LivePhotoConverter
ARCHIVE=build/LivePhotoConverter.xcarchive
EXPORT=build/export
APP="$EXPORT/LivePhotoConverter.app"

xcodebuild -scheme "$SCHEME" -configuration Release \
  -archivePath "$ARCHIVE" archive \
  MARKETING_VERSION="$VERSION" CURRENT_PROJECT_VERSION="$VERSION"

# exportOptions-DeveloperID.plist is generated by macos-release.sh; or create:
# method=developer-id, teamID=$TEAM_ID, signingStyle=manual, signingCertificate=Developer ID Application

xcodebuild -exportArchive -archivePath "$ARCHIVE" \
  -exportPath "$EXPORT" -exportOptionsPlist build/exportOptions-DeveloperID.plist

# Sign again if needed (export usually signs):
codesign --force --options runtime --timestamp \
  --sign "$SIGNING_IDENTITY" "$APP"

ditto -c -k --keepParent "$APP" "build/LivePhotoConverter-${VERSION}.zip"
xcrun notarytool submit "build/LivePhotoConverter-${VERSION}.zip" \
  --keychain-profile "$NOTARY_PROFILE" --wait
xcrun stapler staple "$APP"

./scripts/make-dmg.sh "$APP" "$VERSION"
```
